# เอกสารอ้างอิงย้อนหลัง

เอกสารสำหรับนำเสนออยู่ที่ [สารบัญหลัก](../README.md) โฟลเดอร์นี้เก็บรายละเอียดการตรวจสอบ ผลทดสอบ และเหตุการณ์ในอดีต ข้อมูลอาจไม่ตรงกับระบบปัจจุบัน และไม่ใช่ผลทดสอบใหม่

| เอกสาร | เหตุผลที่เก็บ |
|---|---|
| [requirements-test-evidence.md](requirements-test-evidence.md) | เก็บผลทดสอบและบริบทของการตรวจสอบเดิม |
| [test-evidence.md](test-evidence.md) | เก็บผลทดสอบและบริบทของการตรวจสอบเดิม |
| [reliability/azure-health-patch.md](reliability/azure-health-patch.md) | เก็บรายละเอียดเหตุการณ์หรือการวิเคราะห์ที่ยังมีคุณค่าอ้างอิง |
| [reliability/security-pr.md](reliability/security-pr.md) | เก็บรายละเอียดเหตุการณ์หรือการวิเคราะห์ที่ยังมีคุณค่าอ้างอิง |
| [reliability/transaction-audit.md](reliability/transaction-audit.md) | เก็บผลทดสอบและบริบทของการตรวจสอบเดิม |
| [reliability/validation.md](reliability/validation.md) | เก็บผลทดสอบและบริบทของการตรวจสอบเดิม |

ภาพและ JSON ต้นฉบับยังอยู่ใน [evidence](../evidence/) โดยไม่เปลี่ยนเนื้อหาหรือตำแหน่ง ภาพจากเว็บจริงของชุดเอกสาร v1.0 อยู่ใน [assets/screenshots](../assets/screenshots/)

คู่มือ Flow และ Demo เดิมถูกรวมใน [คู่มือใช้งาน](../user-manual.md) และ [คู่มือนำเสนอ](../presentation-guide.md) แล้ว จึงไม่เก็บไฟล์เนื้อหาซ้ำ ทะเบียนเอกสารเดิมถูกรวมเป็นสารบัญนี้
